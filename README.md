# CodeForces Contests Source Code Repos

## Prerequisites
- Rust
- Cargo
- Just
- Git

## Usage
Start new branch
```bash
git checkout -b contest-<id>
```

Create new contest
```bash
cargo generate --name contest-<id> --git https://github.com/renan-z/code-forces.git --branch template
```

Create new problem
```bash
just create a
```

Work on problem
```bash
just work a
```
